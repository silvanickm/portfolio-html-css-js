# 💻 Portfólio - Nicolas Silva

Aplicação desenvolvida para apresentar minhas habilidades como Desenvolvedor Full Stack, com foco em organização, estrutura semântica e experiência do usuário.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git & GitHub

---

## 🎯 Objetivo do Projeto

Criar uma aplicação simples, moderna e responsiva para demonstrar:

- Estrutura de código organizada
- Separação de responsabilidades
- Responsividade
- Identidade visual consistente
- Integração com GitHub e LinkedIn

---

## 🧩 Funcionalidades

- Layout responsivo
- Seção de projetos com links diretos para repositórios
- Navegação suave entre seções
- Formulário de contato funcional
- Efeitos visuais e animações suaves
